# Day 22: Handle Missing Values Using Pandas

## Objective

To identify and handle missing values in a dataset using Python and Pandas.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Description

In this task, I created a dataset containing missing values and used Pandas to clean the data. I filled missing numerical values using the mean and missing categorical values using the mode.

## Work Performed

* Created a dataset using Pandas.
* Identified missing values using `isnull()`.
* Counted missing values using `sum()`.
* Filled missing Age and Marks values using the mean.
* Filled the missing City value using the mode.
* Verified the cleaned dataset.
* Exported the cleaned dataset to a CSV file.

## Techniques Used

* `pd.DataFrame()`
* `isnull()`
* `sum()`
* `fillna()`
* `mean()`
* `mode()`
* `to_csv()`

## Result

Successfully identified and handled missing values in the dataset. The cleaned dataset was saved as `cleaned_dataset.csv`.

## Conclusion

This task helped me understand basic data cleaning and missing-value handling using Pandas, which are important steps in data preprocessing.
